# First bracket
Run `python3 -m kcee.demo --output runs`. Inspect report.md and manifest.json in the printed run directory; load bracket.stl in the Three.js viewer. Sample inputs: 60×30×40 mm L bracket, 100 N load, illustrative aluminum. Search selects 3.5 mm with analytical FoS 2.45. No holes or fillets. API provides the same fixed pipeline via POST /runs/bracket.
