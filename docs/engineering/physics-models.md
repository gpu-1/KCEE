# Physics models

Structural: CalculiX baseline, FEniCSx for extensible multiphysics. Thermal: conduction/convection boundaries with temperature-dependent materials. CFD: SU2/OpenFOAM. Chemistry: Cantera thermodynamics, transport and kinetics, coupled explicitly to CFD/thermal models. Every adapter must declare units, applicability, convergence and model limitations. Only the bracket analytical screening is implemented.
